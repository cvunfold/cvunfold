# Privacy and retention

Default retention is 30 days and configurable through `REPORT_RETENTION_DAYS`. Source files are deleted immediately after parsing/analysis. The cleanup endpoint requires `CRON_SECRET`. Users can delete a report immediately with their random access token.

Never log CV text, prompts or reports. For failed document extraction, runtime logs may contain only privacy-safe technical diagnostics: document kind (`pdf`/`docx`), a coarse file-size bucket, parser and parser version, page/text-item counts, extracted character count, parser warning count and a closed failure-reason enum. The allowed extraction reasons are `pdf_no_text_items`, `pdf_empty_text_items`, `pdf_page_extraction_failed`, `pdf_parse_failed`, `pdf_encrypted`, `docx_no_text`, `docx_parse_failed` and `text_below_threshold`. Never log the filename, document text, warning/error message, file hash, private URL, access token or contact data. Analytics allow only event names and non-PII acquisition metadata. Vercel Web Analytics runs un-gated because it is cookieless and stores no identifier, so it rests on legitimate interest rather than consent; the URL it reports is rewritten first by `safeVercelAnalyticsUrl`, which drops the fragment (where a report access token lives), collapses report paths, removes the query entirely on report pages and forwards only `utm_*` campaign labels elsewhere. It is deliberately narrower than what Google receives: click identifiers (`gclid`, `gbraid`, `wbraid`) are never sent to Vercel, because only Google Ads has a conversion to attribute with them. Private pages emit `noindex`. Supabase storage must be private; service-role credentials remain backend-only.

For a document rejected as not a CV, the same rule applies: only the numeric heuristic score, the `low`/`medium`/`high` confidence band, the closed list of matched structural signals (which section headings, date patterns or job-title patterns were found — never the matched text itself) and a closed rejection-reason enum may be logged or stored in `funnel_events`. The allowed reasons are `too_short`, `no_career_anchor`, `insufficient_structure` and `low_score`.

The `analysis_started` funnel event may record where its `broad_role_enum` value came from, as two closed enums: `role_source` (`autodetected`, `user_chose`, `not_detected`, `detector_error`, `not_run`) and `detected_role_enum`, which holds the role the detector proposed and is kept even when the visitor overrides it. `detected_role_enum` is drawn from the same closed role list as `broad_role_enum`. This is provenance for a value already recorded, not a new fact about the person: it never carries free text, a custom profession name, any part of the CV, or a confidence score. It exists because `broad_role_enum` is written before the CV is parsed, which makes the form default and a genuine detection indistinguishable.

The model-perceived role may be used once, inside the server/database transaction that stores a completed report, to increment an anonymous audience-fit counter. The permanent aggregate contains only:

- `role_category`: `supported_it`, `other_it`, `unclear`, or one of a closed set of specific non-IT categories (`architecture_construction`, `healthcare_medical`, `legal`, `education_academia`, `finance_accounting`, `sales_marketing`, `hr_recruiting`, `public_sector`, `hospitality_retail`, `creative_arts_media`, `engineering_manufacturing_nonit`, `skilled_trades`, `science_research_nonit`, `other_non_it`) — never free text, so a rare profession stays as anonymous as a common one;
- `source_bucket`: `google_cpc` or `other`;
- `analysis_count`: a cumulative count.

It contains no analysis/report identifier, raw perceived role, timestamp, locale, model or prompt version, IP address, filename, click identifier, UTM, CV content or report content. It is not sent to GA4 or Google Ads and is not used to make a decision about a person. The raw perceived role remains only inside the report and follows report deletion and the 30-day retention limit. Admin diagnostics suppress role cells below five analyses.
