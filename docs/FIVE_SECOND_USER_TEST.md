# Five-second user test

Cel: sprawdzić zrozumienie hero na pięciu osobach, które nie znają produktu. Nie zapisujemy danych CV i nie sugerujemy poprawnych odpowiedzi.

## Procedura

1. Pokaż testerowi desktopowe lub mobilne hero przez 5–10 sekund.
2. Ukryj stronę.
3. Zadaj pytania dokładnie w tej kolejności.
4. Zapisz możliwie dosłowną odpowiedź, bez tłumaczenia produktu.
5. Dopiero po pytaniu 7 pozwól kliknąć i obserwuj pierwszy wybór.

## Pytania

1. Co sprzedaje ta strona?
2. Dla kogo jest produkt?
3. Czym różni się od zwykłego ATS checkera?
4. Co otrzymujesz bezpłatnie?
5. Ile kosztuje pełny raport?
6. Co dzieje się z przesłanym CV?
7. Co kliknąłbyś dalej?
8. Co budzi nieufność?
9. Czy spodziewasz się, że system dopisze fakty?
10. Czy zapłaciłbyś za wynik? Dlaczego?

## Bramka

Co najmniej 4/5 osób bez pomocy powinny rozpoznać: analizę przekazu CV developera, seniority/first impression, bezpłatny teaser, cenę od 29 zł lub €9 i brak dopisywania faktów. Jeżeli różnica vs ATS nie jest spontaniczna u 4/5, nie zwiększamy budżetu reklamowego.
